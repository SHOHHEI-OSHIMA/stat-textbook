この地図の使い方

先に読むべき注意

これは地図であって、territory ではありません。この文書を読み終えても、確率が得意にはならないし、確率が面白いかどうかも分かりません。

あなたがやろうとしているのは「確率論があなたを掴むかどうか」を測ることでした。それを判定できるのは演習問題を自分で解いている最中の感触だけです。地図を読んでいる間の感触ではない。ここは地形の起伏を先に見せて、歩く速度を上げるためだけのものです。

使い方としては、

  • 各章に入る前に、その章の欄を読んで「何のための章か」を先に持っておく
  • 各章を終えた後に、もう一度読んで自分の理解と突き合わせる
  • 「8つの考え」は、13章のどこにいても戻ってくる場所です。詰まったら、いまどの考えを使うべき場面かを問う
  • 橋の節は、他のどこよりも先に読んでいい。あなたが既に持っている直感に接続している唯一の部分です

AIを使わずに解くこと

演習を AI に解かせると、このテストは意味を失います。測ろうとしているのはあなたの理解であって、あなたが監督したAIの出力ではありません。詰まって30分止まる経験そのものが測定値です。

Day 3 · 1h

公理的な定義、包除原理、そして最初の検算

1.6 まで読んで章末問題を5問。うち1問はモンテカルロで検算する（下記）。ここで解析解とシミュレーションが一致する経験を1回作っておくと、以後の学習の速度が変わります。

1セクションあたりのループ

  1. 読む（20〜30分）。動画ではなく本から。本のほうが単位時間あたりの情報が多い
  2. 本を閉じて、何が主張されていたかを書き出す（3分）。これは想起練習で、再読より効率が高い
  3. 問題を解く。ここが本体。読む時間より解く時間のほうが長くなるのが正常です
  4. 詰まった箇所だけ動画を見る。Blitzstein の直感的な説明が効くのは、既に自分で詰まった後です

問題を解くときの3つの規則

  1. 20分は何も見ずに粘る。 手が止まっている20分が、この4週間で最も情報量の多い時間です
  2. 詰まったら、解答ではなく該当節に戻る。 解答は最後の手段
  3. 解答を読んだ問題には印をつけ、翌日ゼロから解き直す。 解答を読むことは、解けるようになることではありません。この規則を守るかどうかが、4週間が機能するかどうかを決めます

すべての答えをモンテカルロで検算する

これはあなたに固有の推奨です。解析的に答えを出したら、毎回15行のシミュレーションで確かめてください。単一の Python ファイルに積んでいく。

たとえば第4章の一致問題 —— n 枚のカードをシャッフルして元の位置に戻る枚数の期待値は、n によらず 1 になります。

import numpy as np
rng = np.random.default_rng(0)
n, trials = 10, 200_000

perm    = np.argsort(rng.random((trials, n)), axis=1)
matches = (perm == np.arange(n)).sum(axis=1)

print(matches.mean())   # → 1.00 前後。n を変えても 1

これが効く理由は三つあります。①検算になる ②理解していない問題はシミュレートできないので、理解の有無が自動的に判定される ③あなたが既に得意なやり方で確率に触れることになるので、初速が上がる。

「剛性の取り違えは反力では出ない」を書いた人にとって、解析解と数値実験を突き合わせる作業は新しい習慣ではないはずです。

講義全体をひとつの文で

Stat 110 は何をする科目か

不確実なものについて、足す・条件をつける・極限をとるという三つの操作を、間違えずに実行できるようにする科目です。

大半の内容はこの三つのどれかです。期待値の線形性は「足す」。条件付き確率・ベイズ・Adam の法則は「条件をつける」。大数の法則・中心極限定理・ポアソン近似は「極限をとる」。名前つき分布は、これらの操作の下で閉じていたり互いに移り合ったりするので名前が付いているだけで、暗記対象ではありません。

Blitzstein がこの科目について繰り返す一文があります —— conditioning is the soul of statistics（条件づけこそが統計の魂である）。詰まったときの最初の一手は、ほぼ常に「知っていたらよかったのに、と思うものは何か。それで条件づけよ」です。

8つの考え

全13章を貫くもの · 順序に意味はない

名前つき分布を全部忘れても、この8つが残っていれば復元できます。逆は成り立ちません。

物語による証明

Story proof

恒等式を、記号操作ではなく「同じものを二通りに数える」ことで示す。C(n,k) = C(n,n−k) は、選ぶ k 個を指定するのと、外す n−k 個を指定するのが同じ行為だから成り立つ —— 階乗を約分する必要はありません。

この習慣が身につくと、式を見たときに「この量は何を数えているのか」を先に問うようになります。それが確率の問題を解く速度をいちばん上げます。

期待値の線形性

Linearity of expectation

E(X + Y) = E(X) + E(Y) は独立でなくても、どんな依存があっても、常に成り立ちます。これが講義中で最も強力な道具で、同時に最も過小評価される道具です。

分散にはこの性質がありません（Var(X+Y) ≠ Var(X)+Var(Y) が一般）。この非対称性が、後で共分散が出てくる理由です。

指示確率変数と基本の橋

Indicator RVs & the fundamental bridge

事象 A に対して IA を「A が起きたら 1、起きなければ 0」とすると E(IA) = P(A)。これが確率の問いを期待値の問いに変換する橋です。

線形性と組み合わせると、独立性が一切なくても答えが出ます。例：n 枚のカードをシャッフルして、i 番目のカードが元の位置に戻る枚数の期待値は n × (1/n) = 1。n によらず 1。位置どうしは明らかに独立でないのに、答えが一行で出る。

LOTUS

Law of the Unconscious Statistician

E(g(X)) = Σ g(x)·P(X=x)（連続なら ∫ g(x)·f(x) dx）。g(X) の分布を求める必要はありません。X の分布のまま重みをかけて足せばよい。

ここに最頻出の罠が同居しています。E(g(X)) ≠ g(E(X))。この差を定量化するのが第10章の Jensen の不等式です。

条件づけこそが魂である

Conditioning is the soul of statistics

知りたいことが直接計算できないとき、知っていたら簡単になるもので場合分けする。全確率の法則 P(A) = Σ P(A|Bi)·P(Bi) がその形式化です。

ベイズの定理 P(A|B) = P(B|A)·P(A)/P(B) は、条件づけの向きを反転させる装置。実務で危険なのは、この二つを取り違えることです（第2章の罠を参照）。

一様分布の普遍性

Universality of the Uniform

連続な CDF F を持つ X について、F(X) ~ Unif(0,1)。逆に F⁻¹(U) ~ X。

つまり 一様乱数さえあれば任意の分布が生成できる。モンテカルロ法の基礎はこの一行です。あなたが応答のばらつき評価で乱数を使ったとき、裏で働いていたのはこれです。

Adam の法則と Eve の法則

Tower property & law of total variance

Adam: E(Y) = E(E(Y|X))。Eve: Var(Y) = E(Var(Y|X)) + Var(E(Y|X))。

Eve の法則は「群内のばらつき + 群間のばらつき」の分解で、分散分析も、地震ハザードの偶然的不確定性と認識論的不確定性の分離も、すべてこの一本の式です。第9章の核心。

対称性

Symmetry

問題が入れ替えに対して不変なら、それを使う。ランダムな並べ替えにおいて「カード i が位置 j に来る確率」は、i と j が何であれ 1/n。数え上げをせずに答えが出ます。

対称性は検算にも使えます。得られた答えが問題の対称性を壊していたら、それは間違いです。

分布の家系図

名前つき分布は暗記項目ではなく、操作で移り合う一つの族

Stat 110 でいちばん誤解されやすいのが、名前つき分布を独立した暗記カードの束だと思うことです。実際には、「和をとる」「極限をとる」「比をとる」という少数の操作で互いに移り合います。矢印のラベル（操作）のほうが、箱（分布名）より重要です。

章ごとの地図

全13章 · 各章 = 何のための章か / 落とさない要点 / 罠

01

確率と数え上げProbability and Counting

「同様に確からしい」という素朴な定義から始め、それが破綻する場面を見てから公理的な定義に移る章。数え上げの道具（乗法原理、二項係数、標本抽出の4類型 = 順序あり/なし × 復元あり/なし）を揃えます。

要点物語による証明。Vandermonde の恒等式 C(m+n,k) = Σ C(m,j)C(n,k−j) を階乗計算ではなく「m 人と n 人から合計 k 人選ぶ」で示せること。包除原理。

罠「同様に確からしい」を検証せずに仮定すること。順序なし復元ありの場合の数は数えられますが、その各々は等確率ではありません。サイコロ2個の目の組を等確率と思うのが典型的な誤り。

02

条件付き確率Conditional Probability

講義の中心思想が入る章。P(A|B) = P(A∩B)/P(B)、ベイズの定理、全確率の法則。モンティ・ホール問題とシンプソンのパラドックスで直感を壊しにきます。

要点ベイズのオッズ形式 事後オッズ = 尤度比 × 事前オッズ。これが実務では最も速い。そして独立と条件付き独立は互いに含意しない（どちらの向きも成り立たない）こと。

罠検察官の誤謬。P(証拠|無実) が小さいことと P(無実|証拠) が小さいことは別物です。基準率を無視すると、稀な病気の検査で陽性が出た人の大半が実は健康、という結論を見落とします。

03

確率変数とその分布Random Variables and Their Distributions

確率変数は標本空間から実数への関数であって、数でも分布でもありません。ここが第一の概念的な段差です。PMF、CDF、そして Bernoulli / Binomial / Hypergeometric / 離散一様。

要点指示確率変数の導入。ここで入れておかないと第4章の威力が出ません。

罠確率変数とその分布の混同。Blitzstein の比喩では、確率変数が家で、分布は設計図です。同じ設計図から建った二軒の家は別の家です。記号でいえば X = Y（関数として同一）と X ~ Y（分布が同じ）は全く違う主張。

04

期待値Expectation

密度がいちばん高い章。線形性、指示変数と基本の橋、LOTUS、分散。Geometric / Negative Binomial / Poisson がここで登場します。

要点ポアソン・パラダイム —— 多数の稀な、ほぼ独立な事象の総数はポアソンで近似できる。クーポン収集問題を線形性だけで解けるようになること。

罠E(1/X) ≠ 1/E(X)、E(X²) ≠ E(X)²。後者の差がまさに分散です。関数と期待値は交換できません。

05

連続確率変数Continuous Random Variables

PDF、CDF、一様分布、正規分布、指数分布。そして一様分布の普遍性。

要点指数分布の無記憶性 —— P(X > s+t | X > s) = P(X > t)。連続分布でこの性質を持つのは指数分布だけです。これは第13章のポアソン過程と地震の発生モデルに直結します。

罠PDF の値を確率だと思うこと。連続変数では P(X = x) = 0 であり、f(x) は 1 を超えても構いません。確率は面積です。

06

モーメントMoments

平均・分散・歪度・尖度が分布の何を要約しているか。そしてモーメント母関数 M(t) = E(e^tX)。

要点MGF は三つの仕事をします。①モーメントを生成する ②分布を一意に定める ③独立な和の MGF は積になる。③のおかげで畳み込み積分を回避できます。

罠MGF は常に存在するとは限りません（コーシー分布には存在しない）。裾の重い分布では平均や分散すら存在しないことがある —— 金融の収益率分布でも、極値荷重でも、これは実際に効いてきます。

07

同時分布Joint Distributions

同時分布・周辺分布・条件付き分布、2次元 LOTUS、共分散と相関、多項分布、多変量正規分布。あなたにとって最も直接的に役立つ章です（橋①参照）。

要点Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y)。この一本が SRSS と CQC の違いそのものです。

罠無相関は独立を意味しません。相関係数が捉えるのは線形関係だけです。例外は同時正規のときで、そのときに限り無相関 ⟺ 独立。

08

変数変換Transformations

変数変換（ヤコビアン）、和の畳み込み、ベータ分布とガンマ分布、順序統計量。

要点順序統計量 —— n 個の標本の最大値・最小値・第 k 位の分布。極値の理論であり、ピーク応答や設計荷重の話に直結します（橋④）。

罠ヤコビアンの忘却と、台（support）の変換忘れ。後者のほうが頻繁で発見しにくい。変換後の変数がどの範囲を動くかを必ず書き出すこと。

09

条件付き期待値Conditional Expectation

講義中で最大の概念的な段差。E(Y|X) は数ではなく確率変数です（X の関数だから）。ここを乗り越えられるかどうかが、確率論に進めるかどうかの分かれ目になります。

要点Adam の法則 E(Y) = E(E(Y|X)) と Eve の法則 Var(Y) = E(Var(Y|X)) + Var(E(Y|X))。加えて、E(Y|X) は二乗誤差の意味で X に基づく Y の最良予測であるという射影としての解釈。

罠E(Y|X) を数だと思うこと。E(Y|X=3) は数ですが、E(Y|X) は確率変数です。この区別がつかないと Adam の法則が意味不明になります。

10

不等式と極限定理Inequalities and Limit Theorems

Cauchy–Schwarz、Jensen、Markov、Chebyshev、Chernoff。そして大数の法則と中心極限定理、χ² 分布と t 分布。

要点Jensen の不等式が第4章の罠を解決します —— 凸関数なら E(g(X)) ≥ g(E(X))。不等式群は「分布が分からなくても言えること」を与える道具です。

罠二つあります。①大数の法則を「次の数回で帳尻が合う」と読む（ギャンブラーの誤謬）。②中心極限定理は裾については何も保証しません。中心付近の近似であり、極値荷重や金融のテールリスクに CLT を持ち込むのは誤りです。極値には第8章の順序統計量と極値理論を使う。

11

マルコフ連鎖Markov Chains

マルコフ性（未来は現在にのみ依存する）、推移行列、状態の分類（再帰的・過渡的）、定常分布、可逆性。

要点既約かつ非周期的なら、任意の初期状態から定常分布に収束する。可逆性（詳細釣り合い）が成り立てば、それは定常分布であることの十分条件 —— これが次章の設計原理になります。

罠定常分布の存在と、長時間後の挙動の収束を同一視すること。周期的な連鎖では定常分布はあるのに収束しません。

12

マルコフ連鎖モンテカルロMCMC

Metropolis–Hastings とギブスサンプリング。正規化定数が分からない分布から標本を得るための技術です。ベイズ推論の実務がここで可能になります。

要点「望む分布を定常分布に持つ連鎖を設計する」という発想の転換。前章の可逆性がそのまま設計の道具になります。

罠収束診断は収束の証明ではありません。トレースプロットが落ち着いて見えることと、連鎖が本当に混合していることは別です。

13

ポアソン過程Poisson Processes

強度 λ の点過程。個数と時間の双対性 —— N(t) ~ Pois(λt) かつ到着間隔 ~ Expo(λ)。重ね合わせ、間引き、条件づけ。

要点間引き（thinning）と重ね合わせ（superposition）で閉じていること。そして N(t)=n で条件づけると、到着時刻は一様分布の順序統計量になるという美しい結果。

罠ポアソン仮定は「事象が互いに独立で、集中しない」ことを要求します。余震は明らかにこれを満たしません。モデルの適用範囲を確認せずに使うと、地震の群発性を無視することになります（橋②）。

構造工学からの5本の橋

あなたが既に使っている確率論 · ここから読み始めてよい

あなたは確率論を応用の形ですでに使っています。測度論から積み上げていないだけで、直感の土台はある。以下はゼロからの学習ではなく、既に知っていることに名前がつく作業です。

橋① SRSS と CQC は、和の分散の式そのもの

モーダル応答を重ね合わせるとき、全応答は R = Σ Ri。各モードのピーク応答を確率変数とみなすと、第7章の式がそのまま出てきます。

Var(Σ Ri)  =  Σi σi²  +  2 Σi<j ρij σi σj

ρij = 0 と仮定 →  σ = √( Σ σi² )        ← SRSS
ρij を残す    →  σ = √( ΣΣ ρij σi σj )   ← CQC

SRSS から CQC への移行は「無相関仮定を捨てる」ことそのものです。固有周期が近接するとモード応答が相関して Cov ≠ 0 になり、SRSS が危険側になる —— この現象の正体は第7章の「無相関 ≠ 独立」ではなく、そもそも共分散項を落としていたことです。

橋② 再現期間475年は、ポアソン過程の一行

地震の発生を強度 λ のポアソン過程とモデル化すると、50年間に少なくとも1回超過する確率は第13章から直ちに出ます。

P(50年間に1回以上)  =  1 − e^(−λ·50)  =  0.10

  λ·50 = −ln(0.90) = 0.10536
  λ     = 0.0021072 /年
  T     = 1/λ = 475 年

つまり「50年超過確率10%」と「再現期間475年」は同じ主張の二つの書き方です。あなたが規準で何度も見た数字の出どころがこれです。

そして第5章の無記憶性が「前回から100年経ったからそろそろ起きやすい」を否定します。地震学ではここが論争点で、特性地震には更新過程（BPT分布など）を使う立場がある —— これは確率モデルの選択が工学的結論を変える、生きた実例です。

橋③ 限界状態設計は P(R < S) の計算

性能関数を g = R − S（耐力 − 荷重効果）とすると、破壊確率は pf = P(g < 0)。R と S を独立な正規と仮定すれば、第5章と第7章だけで信頼性指標が出ます。

g ~ N( μR − μS ,  σR² + σS² )

β  =  (μR − μS) / √( σR² + σS² )
pf =  Φ(−β)

荷重係数と材料係数は、目標 β から逆算されたものです。規準の数字の背後にあるのは、この二行。ここを知ってから規準を読むと、係数が「決まりごと」から「導出された量」に変わります。

橋④ ランダム振動論はモーメントとスペクトルの言い換え

定常ランダム過程に対する線形系の応答分散は、パワースペクトル密度の重みつき面積です。

σresponse²  =  ∫ |H(ω)|² · Sinput(ω) dω

これは第6章（モーメント）と第7章（共分散）の連続版で、S(ω) は自己相関関数のフーリエ変換です。そしてピーク係数（Davenport など）が扱っているのは第8章の順序統計量と極値。

あなたが免震の防振でやった「理論と計測の突き合わせ」は、この枠組みの中の作業です。 理論側が |H(ω)|²·S(ω) の予測で、計測側が実現した1本の標本経路 —— 乖離を議論するには、そもそも「1本の標本と分布の予測を比べている」という構図を自覚する必要があります。それが確率論の言葉です。

橋⑤ Eve の法則は、ばらつきの分解そのもの

Var(Y)  =  E[ Var(Y|X) ]  +  Var( E[Y|X] )
           群内のばらつき      群間のばらつき

応答のばらつきを「地震動記録ごとのばらつき（偶然的不確定性）」と「モデル・パラメータの不確かさ（認識論的不確定性）」に分けるとき、使っているのはこの式です。地震ハザード解析のロジックツリーも同じ構造。

第9章さえ理解すれば、この分解を自分で導けるようになります。既存の分類を暗記するのではなく。

検算の作法

この科目であなたが最も有利な部分

Stat 110 は答え合わせの文化が強い科目です。Blitzstein は解答を出した後の確認手順を繰り返し要求します —— そしてこれは、あなたが既に自分の仕事でやっていることと同じです。

  • 0 と 1 の間にあるか。 確率のはずのものが 1.4 になっていたら、そこで止まる
  • 極端な場合を入れる。 n=1、n=2、p=0、p=1。ほとんどの誤りはここで死にます
  • 次元・単位を見る。 時間の期待値のはずが無次元になっていないか。構造の検算とまったく同じ習慣です
  • 極限を取る。 n→∞ で答えは正しく振る舞うか
  • 対称性を壊していないか。 問題が i と j の入れ替えに対して不変なら、答えもそうでなければならない
  • シミュレートする。 30行の Python が1時間の議論に勝ちます。解析解とモンテカルロが合わなければ、どちらかが間違っている

あなたの既存の習慣が、そのまま効く

「剛性の取り違えは反力では出ない」—— 釣り合いだけを見るチェックは構成則の誤りに対して構造的に盲目である、という気づきは、確率論では次の形で現れます。期待値だけを合わせても分布は決まらない。平均が一致していても、分散が、裾が、まったく違う分布はいくらでもあります。

問うべきは常に同じです —— この検算が原理的に見られないものは何か。

以下はこの本（と講義）の中だけの用語です。日本語の教科書にも、他の英語の教科書にも出てきません。逆に言えば、これを知らないまま検索しても何も出ません。

訳語の罠

  • support = 台。確率変数が正の確率を持つ範囲。「サポート」ではないし、字面から推測できない
  • distribution は「分布」ですが、日本語の 「分布関数」は CDF を指すことが多い。英語の distribution は分布そのもの
  • moment は日本語で積率とモーメントの両方が使われます。同じもの
  • expectation と mean は英語ではほぼ同義ですが、日本語では期待値（理論値）と平均（標本値）が区別されがち。文脈で判断する
  • density（密度・連続）と mass（質量・離散）の対比は、日本語だと「密度関数／質量関数」で見えにくい。英語のほうが構造が明快です
