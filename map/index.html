統計は合流点である

3科目ではなく、2つの土台と1つの合流

確率・統計・最適化を「3つの別々の科目」として並べると、道に迷います。実際の構造はこうです。

確率    …  不確実なものを記述する言語
最適化  …  「最も良いもの」を見つける方法

統計    …  その2つの合流点
             「観測から、最ももっともらしいモデルを見つける」

最尤推定は尤度という関数の最大化です。最小二乗法は二次形式の最小化。正則化は制約付き最適化。ベイズの MAP 推定は事後確率の最大化。統計の主要な手法は、ほぼ例外なく「確率で目的関数を書き、最適化で解く」という形をしています。

だから 確率と最適化は並行して学べます。互いに前提ではないので、片方に飽きたらもう片方へ移れる。独学の継続にはこれが効きます。

最適化は、あなたにとって最も入りやすい入口かもしれません

Boyd の『Convex Optimization』は多くの人にとって抽象的で辛い本ですが、変分原理とニュートン法を実装した経験がある人には具体的に読めます。「なぜ凸性が効くのか」は、剛性行列が正定値なら解が一意で安定であることと同じ話です。

そして最適化は確率を前提としません。Stat 110 と並行して今すぐ始められます。

足りない可能性があるもの

  • 理論的な線形代数。使えることと、証明できることは別です。ベクトル空間・双対・射影・スペクトル定理を定義から追えるか。不安なら Strang（MIT 18.06、動画無料）で3週間
  • 解析学の作法。ε-δ、収束、一様収束。測度論に進むなら必須。当面は後回しでよい
  • 証明を書く訓練。工学部では書く機会が少ない。数理統計の演習で自然に鍛えられます

Boyd を最初の3か月に入れることを強く勧めます。 理由が3つあります。

  • 確率を前提としないので、Stat 110 と完全に並行できる。片方に飽きたら切り替えられる
  • あなたのFEM経験が最も直接効く場所。双対性以外はほぼ既知の概念の言い換えです
  • 統計の第3段階（統計的学習）に入る前に済ませておくと、正則化・SVM・スパース推定が「最適化問題を解いているだけ」に見える

同じ式が別の名前で

合流点は抽象論ではなく、具体的な式の一致として現れる

CQC とポートフォリオ分散は同じ式です

CQC（構造）      R²  =  Σᵢ Σⱼ  ρᵢⱼ · Rᵢ · Rⱼ

Markowitz（金融）  σₚ² =  Σᵢ Σⱼ  ρᵢⱼ · σᵢwᵢ · σⱼwⱼ   =  wᵀ Σ w

同じ二次形式。相関行列を挟んで重みつきで足しているだけ。

そして分散投資の効果は SRSS そのものです。資産が無相関なら、リスクは n ではなく √n でしか増えない —— モード応答が無相関なら合成応答が √(Σσᵢ²) になるのと、まったく同じ現象です。

Markowitz のポートフォリオ最適化は「wᵀΣw を制約下で最小化する」二次計画問題。あなたはこの二次形式を、剛性行列とひずみエネルギーの形で既に何百回も扱っています。

ほかの一致

構造工学での姿統計・最適化での姿
最小ポテンシャルエネルギー原理凸関数の最小化。解の一意性は正定値性から
Newton–Raphson の反復ニュートン法。Hessian は接線剛性行列
モード分解主成分分析（PCA）
モデル更新・逆解析ベイズ推論 + MAP 推定（最適化）
カルマンフィルタ（SHM で使う）逐次ベイズ更新 + 線形射影
感度解析勾配・随伴法（adjoint）
信頼性指標 β制約付き最小化（FORM は最適化問題）

この一致が意味すること

あなたは3つの分野をゼロから学ぶのではなく、既に知っている数学に、別の分野での名前と解釈を追加していく作業をすることになります。これは独学の速度に決定的に効きます。

そしてこの「同じ式が別の名前で現れる」経験そのものが、あなたが第1章で学ぶstory proof の精神 —— 同じものを二通りに見る —— の大きい版です。

18か月の順序

週 8〜10 時間を想定 · 2本を並行させる

Month 1–3

確率論 ＋ 凸最適化（並行）

Blitzstein を進めながら、Boyd の第1〜5章（凸集合・凸関数・凸問題・双対性）。2本走らせるのは負荷ではなく保険です。片方で詰まったときに手が止まらない。

Boyd は EE364a の講義動画が無料で、こちらも英語の練習になります。

Month 4–9

数理統計 ＋ 最適化アルゴリズム

久保川（または Casella–Berger）で推定・検定・漸近論。並行して Boyd の後半（内点法）と Nocedal–Wright。ここが最も重い6か月で、しかしいちばん報われる区間です。

この時点で「データからモデルを推定する」を原理から理解した状態になります。

Month 10–14

ベイズ統計と MCMC

McElreath で直感を作り、BDA3 へ。MCMC は自分で実装してください（Metropolis–Hastings なら50行）。

ここがあなたの目的地のひとつです。免震の実測データでベイズ的モデル更新をやれるのはこの段階から。

Month 15–18

分岐 — 目的で選ぶ

構造・研究に寄せるなら：統計的学習（ESL）＋ 不確実性定量化。カルマンフィルタと状態空間モデル。

クオンツに寄せるなら：時系列（Hamilton）＋ 測度論的確率 → Shreve。ここから更に12〜18か月。

どちらも保留なら：ESL を進めるのが最も潰しが効きます。統計と最適化の両方を使うので、どちらの方向にも接続します。

書きながら学ぶ

あなたの最短路 · 読むだけにしない

あなたは実装で理解する型の人です。各段階に実装課題を紐づけてください。理解していないものは実装できないので、進捗の判定が自動化されます。

学ぶもの書くもの
確率論各章の解析解を検証するモンテカルロ（すでに開始済み）
凸最適化勾配降下法・ニュートン法・対数バリア内点法をゼロから
数理統計最尤推定を数値最適化で解く。ブートストラップで信頼区間
ベイズ統計Metropolis–Hastings を自分で書く（約50行）
統計的学習Ridge / Lasso を自分の最適化ソルバで解く
時系列カルマンフィルタ。状態空間モデルの尤度を書く

最終課題として置いておくもの

自分の免震の実測データで、ベイズ的モデル更新をやる。

剛性・減衰・デバイス特性を事前分布で置き、計測を尤度として、MCMC で事後分布を得る。「理論と計測の乖離」が、パラメータの不確かさとモデル誤差に分解されて出てきます。

これに必要なのは 確率論・数理統計・ベイズ・MCMC・数値最適化 —— 上の道筋のほぼ全部です。目的地を先に決めておくと、途中の科目が「なぜ要るのか」で迷わなくなります。そして完成すれば、それは論文にも社内の技術資料にもなる実物です。

ひとつだけ注意

この道筋は年収に直結しません。数学は土台であって、換金できる技能ではない。もし年収が主目的なら、別の設計になります。
