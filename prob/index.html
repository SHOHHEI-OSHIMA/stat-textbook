Chapter 1 · Probability and Counting

確率と数え上げ

舞台を作る章です。確率変数も期待値もまだ出てきません。高校の確率の焼き直しに見えますが、決定的に違う点がひとつあります —— 素朴な定義が壊れる場面を先に見せてから、公理へ移るという構成です。章の順序そのものが議論になっている。

1.1　標本空間と事象

定義

実験（experiment）とは、結果が事前に確定していない試行。
標本空間（sample space） S とは、起こりうる結果すべての集合。
事象（event）とは、S の部分集合。

コインを2回投げるなら S = {HH, HT, TH, TT}。「少なくとも1回は表」という事象は {HH, HT, TH} です。

ここで押さえるべきは、事象は集合であって、日本語の文ではないということ。日本語の文を集合演算に翻訳する作業が、実はこの章の隠れた本体で、ここが雑なままだと第2章で必ず詰まります。

日本語集合英語
A または B（少なくとも一方）A ∪ BA or B / A union B
A かつ B（両方とも）A ∩ BA and B / A intersect B
A は起きないAᶜnot A / A complement
A は起きるが B は起きないA ∩ BᶜA but not B
A と B のちょうど一方(A∩Bᶜ) ∪ (Aᶜ∩B)exactly one of A and B
A も B も起きないAᶜ ∩ Bᶜ = (A∪B)ᶜneither A nor B
A ならば BA ⊆ BA implies B

ド・モルガンの法則（De Morgan's laws）

(A ∪ B)ᶜ  =  Aᶜ ∩ Bᶜ     「A または B が起きる、ではない」＝「A も起きず B も起きない」
(A ∩ B)ᶜ  =  Aᶜ ∪ Bᶜ     「両方は起きない」＝「少なくとも一方は起きない」

これは実務でも効きます。「少なくとも1つ」を直接数えるのが難しいとき、余事象の「1つも起きない」に置き換えると一気に簡単になる —— この定石はド・モルガンの言い換えです。誕生日問題があとで出てきますが、まさにこれです。

1.2　小石の世界

有限の標本空間を、小石が並んだ平面として見ます。この本を通じて何度も戻ってくる絵なので、最初に入れておきます。

  • 結果ひとつ ＝ 小石ひとつ
  • 各小石には質量（＝確率）がある。全部の質量の合計は 1
  • 事象 ＝ 小石の集まり（部分集合）
  • 事象の確率 ＝ その集まりの質量の合計

この絵が効いてくる場所

第2章の条件付き確率は、この絵の中では「B に入らない小石を取り除き、残った小石の質量を合計1になるよう再スケールする」操作として見えます。P(A|B) = P(A∩B)/P(B) の分母は、まさにその再スケール係数です。公式を覚える前にこの絵を持っておくと、第2章が「なぜそうなるか」ではなく「そうとしか書けない」に変わります。

1.3　素朴な定義と、その限界

定義 — 素朴な確率 naive definition
Pnaive(A)  =  |A| / |S|     A に含まれる結果の個数 ÷ 全結果の個数

前提が2つあります。 ① S が有限であること　② すべての結果が同様に確からしい（equally likely）こと。

高校で習う確率はほぼこれです。そして②を確認せずに使うのが、この章で最も多い誤りです。

壊れる例

  • 「明日は雨が降るか降らないかのどちらかだから、確率は 1/2」—— 2つの結果が同様に確からしい根拠がどこにもありません
  • 「宝くじは当たるか外れるかだから 1/2」—— 同じ誤り。標本空間の分割の仕方は確率を決めません
  • 「サイコロ2個の目の組は21通りだから⋯」—— これは 1.4 節で潰します

素朴な定義が正当化されるのは、対称性が等確率を保証している場合に限られます。公平なコイン、公平なサイコロ、よく切ったカード、無作為抽出。この4つのどれかに帰着できるかを毎回問うてください。

そして「等確率でないなら確率とは何なのか」に答えるのが 1.6 節（公理的定義）です。

1.4　数え上げ

素朴な定義を使うには |A| と |S| を数える必要があります。ここが第1章の分量の大半です。

乗法原理（the multiplication rule）

定理

実験Aに n₁ 通りの結果があり、Aのそれぞれの結果に対して実験Bに n₂ 通りの結果があるなら、合わせて n₁n₂ 通り。

大事なのは「それぞれの結果に対して」の部分です。条件は第2段階の選択肢の個数が一定であることで、選択肢の中身は第1段階によって変わって構いません。トランプから2枚引くとき、2枚目は「1枚目が何であれ」51通り。中身は依存するが個数は一定なので、掛けてよい。

標本抽出の4類型（the sampling table）

n 個から k 個を選ぶ。「順序を区別するか」×「同じものを2回選べるか」で4通り。暗記せず、毎回導出できるようにしてください。

順序あり ordered順序なし unordered
復元あり
with replacement		 nk
毎回 n 通りが k 回		 C(n+k−1, k)
等確率ではない
復元なし
without replacement		 n(n−1)⋯(n−k+1)
選ぶたびに1つ減る		 C(n, k)
左を k! で割る		 
C(n, k)  =  n(n−1)⋯(n−k+1) / k!  =  n! / ( k! (n−k)! )

英語では n choose k と読む。 ₙCₖ と習った人には聞き取れないので注意。

この表で唯一の罠

順序なし・復元ありのセルは場合の数としては正しいが、その各々は等確率ではありません。図で見るのが一番速い。

重複の調整（adjusting for overcounting）

数えにくい対象を数えるときの定石。まず区別をつけて数え、あとで重複度で割る。 MISSISSIPPI の並べ替えなら、11文字を別物として 11! 通り数えてから、I が4つ・S が4つ・P が2つの入れ替えで割る。

11! / ( 1! · 4! · 4! · 2! )  =  34,650

使える条件は重複度がすべての対象で等しいこと。C(n,k) の導出もこの原理の一例です。

1.5　物語による証明

恒等式を、代数計算ではなく「同じものを二通りに数える」ことで示す方法。この章の山場です。

01

C(n, k) = C(n, n−k)

物語： n 人から k 人の委員会を作る。左辺は「入る k 人」を指定する数え方。右辺は「入らない n−k 人」を指定する数え方。どちらも同じ行為なので場合の数は等しい。階乗の約分は不要です。

02

n · C(n−1, k−1) = k · C(n, k)

物語： n 人から「k 人の委員会と、その中のキャプテン1人」を選ぶ。何を先に決めるかを変えると、二通りの数え方になります。

03

Vandermonde の恒等式

C(m+n, k)  =  Σj  C(m, j) · C(n, k−j)

物語： 男性 m 人と女性 n 人、合わせて k 人を選ぶ。全体からまとめて選べば左辺。「男性から何人選ぶか」を j として場合分けして足せば右辺。

代数的に示そうとすると面倒ですが、物語なら一行です。この恒等式は第3章で超幾何分布の確率が足して1になることの証明に、そのまま再登場します。

なぜこの技法が重要か

身につくのは恒等式の知識ではなく、式を見たときに「この量は何を数えているのか」を先に問う習慣です。これが確率の問題を解く速度をいちばん上げます。第4章で一致問題の期待値が n によらず 1 になるのも、物語で見れば一行です。

1.6　公理と包除原理

素朴な定義は等確率を要求するので、一般には使えません。そこで発想を変えます —— 「確率とは何か」に答えるのをやめ、「確率が満たすべき性質」だけを決める。

定義 — 確率空間
① P(∅) = 0 ,  P(S) = 1

② 可算加法性 —— A₁, A₂, … が互いに排反なら
     P( ∪ⱼ Aⱼ )  =  Σⱼ P(Aⱼ)

要求はこの2つだけです。ここから確率について使うほぼすべてが導かれます。

P(Aᶜ)  =  1 − P(A)                        余事象
A ⊆ B  ⟹  P(A) ≤ P(B)                     単調性
P(A ∪ B)  =  P(A) + P(B) − P(A ∩ B)       包除原理

公理化が意味していること

確率が「長期的な頻度」なのか「主観的な確信度」なのかという論争は、今も続いています。コルモゴロフの公理化がやったのは、その論争から数学を切り離したことです。解釈が何であれ、上の2条件を満たす限り数学は同一に走る。

構造工学に引きつければ、材料モデルの物理的解釈が何であれ、構成則が満たすべき条件（客観性、熱力学的整合性）を満たしていれば定式化は成立する、という関係に近い。解釈と形式の分離です。

包除原理（inclusion-exclusion）

一致問題（the matching problem）

n 人がパーティで帽子を預け、帰りにランダムに1つずつ取る。少なくとも1人が自分の帽子を取る確率は？ Ai を「i 番目の人が自分の帽子を取る」として包除原理を適用し整理すると、

P(少なくとも1人一致)  =  1 − 1/2! + 1/3! − 1/4! + ⋯ ± 1/n!

n → ∞ で   →  1 − e⁻¹  ≈  0.632

直感に反する結果です。人数を100人にしても1万人にしても、確率は約63%から動きません。 「大人数なら誰か一致しそう」でも「大人数なら自分のは当たりにくい」でもなく、ちょうど釣り合う。第4章で期待値を使って再訪します。

1.7　検算つき例題

解析的に出した答えを、必ずシミュレーションで確かめてください。理解していない問題はシミュレートできないので、理解の有無が自動的に判定されます。以下は numpy だけで動きます。

01

誕生日問題（the birthday problem）

k 人のうち少なくとも2人の誕生日が一致する確率。「少なくとも」なので余事象を取る。

P(全員違う)  =  365 · 364 ⋯ (365−k+1) / 365k
P(一致あり)  =  1 − P(全員違う)

k = 23 のとき  →  0.5073
import numpy as np
rng = np.random.default_rng(0)
k, trials = 23, 200_000

b   = np.sort(rng.integers(0, 365, size=(trials, k)), axis=1)
dup = (np.diff(b, axis=1) == 0).any(axis=1)

print(dup.mean())   # → 0.507 前後

23人で50%を超える理由は、比較の回数が人数ではなく C(23,2) = 253 組だからです。人数の直感と組数の実体がずれている。

02

一致問題

n, trials = 10, 200_000

perm = np.argsort(rng.random((trials, n)), axis=1)
hit  = (perm == np.arange(n)).any(axis=1)

print(hit.mean(), 1 - np.exp(-1))   # → 0.632 前後、一致

n を 5, 10, 100, 1000 と変えて、答えが動かないことを自分の目で確かめてください。解析解を信じる前に「動かない」という事実を先に見るほうが記憶に残ります。

03

サイコロの罠を実測で潰す

d = rng.integers(1, 7, size=(trials, 2))
print((d.sum(axis=1) == 7).mean())   # → 0.1667 = 1/6

# 誤答の 1/7 ≈ 0.1429 とは明確に違う

「順序なし21通り」が誤りであることが、議論ではなく数値で決着します。等確率の仮定が破れているか迷ったときは、常にこの方法で判定できます。

Chapter 2 · Conditional Probability

条件付き確率

ここから本体が始まります。第1章の確率は「情報が与えられていない状態」のものでした。この章では情報が入ってきたときに確率がどう更新されるかを扱います。Blitzstein がこの科目全体について言う一文が、ここで出てきます —— conditioning is the soul of statistics。

2.1　条件づけとは何か

定義
P(A | B)  =  P(A ∩ B) / P(B)        （ P(B) > 0 のとき ）

英語では the probability of A given B。縦棒は given と読みます。

公式そのものより、絵で理解するほうが速い。小石の世界に戻ります。

重要な注意。 P(A|B) は「A と B の順序」ではなく「B という世界の中での A」です。P(A|B) と P(B|A) はまったく別の量で、これを混同するのが 2.4 節の検察官の誤謬です。

2.2　3つの基本定理

定理
乗法法則            P(A ∩ B)  =  P(B)·P(A|B)  =  P(A)·P(B|A)

ベイズの定理        P(A|B)  =  P(B|A)·P(A) / P(B)

全確率の法則        A₁,…,An が S の分割なら
                     P(B)  =  Σᵢ P(B|Aᵢ)·P(Aᵢ)

3つとも、定義から一行で出ます。乗法法則は定義を移項しただけ。ベイズは P(A∩B) を二通りに書いて等号で結んだだけ。全確率の法則は、B を分割の各片との交わりに分けて足しただけです。

これらを組み合わせたのが実務形です。

P(Aᵢ | B)  =  P(B|Aᵢ)·P(Aᵢ)  /  Σⱼ P(B|Aⱼ)·P(Aⱼ)

分母の P(B) は直接分かることが稀なので、全確率の法則で書き下す —— これがベイズを実際に使うときの標準手順です。

この科目でいちばん使う一手

「知っていたらよかったのに、と思うものは何か。それで条件づけよ。」

全確率の法則は、この方針の形式化です。P(B) が直接計算できないとき、B を「もし Aᵢ だったら」に分解して足す。詰まったときの第一手は、ほぼ常にこれです。

2.3　オッズ形式

ベイズの定理には、暗算に向いた書き方があります。分母を計算しなくて済むのが利点です。

オッズ形式のベイズ
P(A|B)      P(B|A)     P(A)
────────  =  ────────  ×  ────────
P(Aᶜ|B)     P(B|Aᶜ)    P(Aᶜ)

事後オッズ  =  尤度比 × 事前オッズ
posterior odds = likelihood ratio × prior odds

オッズ p/(1−p) と確率は相互に変換できます（p = odds/(1+odds)）。証拠が積み重なる場面では尤度比を掛けていくだけになるので、この形が圧倒的に速い。次節で実際に使います。

2.4　基準率と検察官の誤謬

この章で最も実害のある誤りです。P(B|A) と P(A|B) の取り違え —— 具体的には、基準率（base rate）を無視すること。

設定

  • ある病気の有病率は 1%（これが基準率）
  • 検査の感度は 95%：病気なら 95% で陽性　P(+|D) = 0.95
  • 検査の特異度も 95%：健康なら 95% で陰性　P(+|Dᶜ) = 0.05

陽性が出た。病気である確率は？ 多くの人が「95%くらい」と答えます。

P(D|+)  =  P(+|D)·P(D) / [ P(+|D)·P(D) + P(+|Dᶜ)·P(Dᶜ) ]

        =  0.95 × 0.01 / ( 0.95 × 0.01  +  0.05 × 0.99 )

        =  0.0095 / ( 0.0095 + 0.0495 )  =  0.0095 / 0.059

        ≈  0.161   —— つまり約 16%。陽性の 8 割超は偽陽性。

オッズ形式なら暗算できます。事前オッズは 1:99、尤度比は 0.95/0.05 = 19。事後オッズは 19:99、確率に直して 19/118 ≈ 0.161。

検察官の誤謬（the prosecutor's fallacy）

法廷で「この DNA が偶然一致する確率は100万分の1です」と言われたとき、それは P(証拠 | 無実) です。知りたいのは P(無実 | 証拠) のほう。容疑者集団が大きければ、後者はまったく小さくならないことがあります。

同じ構造の誤りは実務にも現れます。「この異常値が正常な計測で出る確率は 0.1% だから、異常に違いない」—— 計測回数が十分多ければ、正常でも普通に出ます。

2.5　独立性

定義
A と B が独立  ⟺  P(A ∩ B)  =  P(A)·P(B)

同値な言い方（P(B) > 0 のとき）:  P(A|B) = P(A)
                              「B を知っても A の確率が変わらない」

独立と排反はまったく別の概念です

初学者が最も混同するのがここです。排反（disjoint）な2つの事象は、確率が正である限り独立ではありません。 むしろ最大限に依存しています —— 一方が起きたら他方は絶対に起きないのだから、これ以上ないほど情報を持っている。

絵で言えば、排反は小石が重ならないという配置の話。独立は割合が保たれるという質量の話です。A ∩ B = ∅ なら P(A∩B) = 0 なので、P(A)P(B) > 0 と一致しません。

3つ以上の独立には注意が必要です。「どの2つを取っても独立（pairwise independent）」であっても、3つまとめて独立とは限りません。相互独立（mutually independent）はすべての部分集合について積が成り立つことを要求します。

2.6　条件付き独立

定義
A と B が C のもとで条件付き独立
   ⟺  P(A ∩ B | C)  =  P(A|C) · P(B|C)

独立と条件付き独立は、どちらも他方を含意しません。 両方向とも成り立たない。これは重要なので、反例を両方向とも自分で作れるようにしてください。

独立だが、条件付き独立でない

公平なコインを2回投げる。A＝1回目が表、B＝2回目が表。これは独立です。ここで C＝「2回の結果が同じ」で条件づけると、C のもとでは1回目が表なら2回目も必ず表。完全に従属します。

条件付き独立だが、独立でない

同じ患者に独立な検査を2回行う。D＝病気であるとして、D の値を固定すれば2つの検査結果は独立です。しかし D を知らなければ、1回目が陽性だと2回目も陽性になりやすい（どちらも同じ病状を反映するから）。無条件では従属です。

なぜこれが重要か

後者の構造はあらゆる測定に現れます。同じ対象を2回測れば、真値を固定すれば誤差は独立でも、真値を知らなければ2つの測定値は相関する。「相関しているから何か関係がある」ではなく「共通の原因で条件づけていないだけ」という場合が非常に多い。

この区別は第7章の共分散、そして交絡（confounding）の議論に直結します。

2.7　モンティ・ホール問題

3つの扉のうち1つに賞品。あなたが1つ選んだあと、司会者が残り2つのうちハズレの扉を必ず開けます。選び直すべきか？

答え：選び直すべき。 勝率は 1/3 から 2/3 に上がります。全確率の法則で確かめます。S＝選び直して勝つ、として最初の選択で条件づけると、

P(S)  =  P(S | 最初が当たり)·(1/3)  +  P(S | 最初がハズレ)·(2/3)
      =        0        ·(1/3)  +        1        ·(2/3)  =  2/3

最初がハズレなら（確率 2/3）、司会者はもう一方のハズレを開けるしかないので、残った扉が必ず当たり。選び直すと「最初にハズレを引く」ことが勝ち条件に変わるのがこの問題の核心です。

前提が効いています

この答えは「司会者は必ずハズレの扉を開ける」「司会者は中身を知っている」という前提に依存します。司会者がランダムに開けてたまたまハズレだった場合、答えは 1/2 になります。条件付き確率は、条件の与えられ方に敏感です。 問題文のどこが条件を定めているかを毎回確認してください。

2.8　シンプソンのパラドックス

すべての部分集団で A が B より優れているのに、全体で集計すると B のほうが優れて見えることがあります。矛盾ではなく、集計が交絡を持ち込んでいるだけです。

術式軽症重症合計
A81/87 = 93%192/263 = 73%273/350 = 78%
B234/270 = 87%55/80 = 69%289/350 = 83%

術式 A は軽症でも重症でも B より成功率が高いのに、合計では B が上回っています。理由は単純で、A は重症例に多く使われているからです。「重症度」で条件づけずに集計したことが原因。

教訓： 比較するときは、比較を歪めうる変数で条件づけているかを確認する。これは第9章の条件付き期待値、そして因果推論の入口です。

2.9　検算つき例題

01

基準率をシミュレーションで確かめる

import numpy as np
rng = np.random.default_rng(0)
n = 2_000_000

disease = rng.random(n) < 0.01
p_pos   = np.where(disease, 0.95, 0.05)
positive = rng.random(n) < p_pos

print(disease[positive].mean())   # → 0.161 前後

手計算の 0.161 と一致します。直感（95%）と実測（16%）の差を、自分の画面で見ておくことに意味があります。

02

モンティ・ホール

n = 500_000
prize  = rng.integers(0, 3, n)     # 賞品の扉
choice = rng.integers(0, 3, n)     # 最初の選択

# 選び直すと、最初がハズレのときだけ勝つ
print("stay  :", (choice == prize).mean())   # → 0.333
print("switch:", (choice != prize).mean())   # → 0.667

コードが2行で済むこと自体が、この問題の構造を表しています。「選び直す＝最初にハズレを引けば勝ち」と言い換えられた時点で、答えは出ています。

03

条件付き独立の反例を作る

n = 1_000_000
f1 = rng.integers(0, 2, n)
f2 = rng.integers(0, 2, n)

# 無条件では独立
print(((f1==1)&(f2==1)).mean(), (f1==1).mean()*(f2==1).mean())

# C = 「2回の結果が同じ」で条件づけると従属になる
C = (f1 == f2)
print((f2[C&(f1==1)]==1).mean())   # → 1.0（完全従属）
