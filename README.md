# 道具箱 (枠なし版)

スマホのホーム画面から全画面で開くための配布版。`/` が入口の道具箱で、
そこから各ページへその場で切り替わります (新しいタブは開きません)。

| 置き場 | 中身 | 正本 |
|---|---|---|
| `/` | 道具箱 (入口) | `build_site.py` が生成 |
| `/textbook/` | 統計学 自分用教科書 | `OneDrive/統計/textbook/src/*.md` |
| `/prob/` | 確率論 自習書 | Artifact から取り出した HTML (2026-08-23 版) |
| `/map/` | 確率から最適化まで | 同上 |
| `/stat110/` | Stat 110 の骨格 | 同上 |

組み立ては `OneDrive/統計/textbook/build_site.py` の出力をそのまま置いています。
ここを直接編集しても次の生成で消えます。

- 株の研究ノートは**載せていません** (仮説と採否の記録が読めるため)。道具箱からは claude.ai の Artifact 版へ飛ばしています
- 端末をまたぐ読書の進捗の同期はありません (Artifact 版のみ)
- 検索には出しません (noindex + robots.txt)
